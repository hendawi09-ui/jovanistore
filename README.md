# Jovani Store — نسخة Next.js

نسخة معاد بناؤها بالكامل بـ React/Next.js (App Router) من نموذج HTML الأصلي، جاهزة للتطوير والنشر الحقيقي.

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## البنية

```
app/
  layout.js          تخطيط عام + الخطوط
  page.js             الصفحة الرئيسية
  product/[id]/       صفحة تفاصيل المنتج
  checkout/           صفحة الدفع
  orders/             صفحة طلباتي
  admin/               لوحة تحكم المنتجات
components/            المكونات المشتركة (الهيدر، الفوتر، السلة، الخلفية التفاعلية...)
lib/
  StoreContext.js      حالة التطبيق (منتجات/سلة/طلبات) + حفظ في localStorage
  products.js          بيانات المنتجات الافتراضية
  icons.js             أيقونات SVG
```

## الحالة الحالية

- البيانات (منتجات، سلة، طلبات) محفوظة في `localStorage` بالمتصفح — تعمل فوريًا بدون خادم لكنها **ليست قاعدة بيانات حقيقية** (كل متصفح له بياناته الخاصة، ولا يوجد أمان حقيقي على لوحة التحكم).
- العملة معروضة بالجنيه المصري (ج.م) كتحضير للسوق المصري.

## الخطوات التالية (نحو موقع إنتاجي حقيقي)

1. **قاعدة بيانات حقيقية**: استبدال `localStorage` بقاعدة بيانات (مثل Supabase/PostgreSQL) عبر Route Handlers في `app/api/`.
2. **حماية لوحة التحكم**: إضافة تسجيل دخول (مثل NextAuth.js) قبل السماح بالوصول لـ `/admin`.
3. **بوابة دفع مصرية**: ربط باي موب (Paymob) أو كاشير (Kashier) عبر Route Handler يستقبل الـ webhook ويحدّث حالة الطلب.
4. **الدومين**: توجيه دومين حقيقي (.com أو .com.eg) إلى Vercel.
5. **الشحن**: ربط API شركة شحن (Bosta / Mylerz) لتحديث حالة الطلب تلقائيًا.

## النشر على Vercel

```bash
npm install -g vercel
vercel
```

أو اربط المستودع مباشرة من [vercel.com](https://vercel.com) بحساب GitHub — كل push على الفرع الرئيسي سيُنشر تلقائيًا.
